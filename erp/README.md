# ERP web app

Vite + React web version of the billing app, with a small SQLite API (`server/`, `node:sqlite`) that stores data in `data/erp.db` (git-ignored, real data).

```bash
npm install
npm run dev   # http://localhost:5173
```

See `../docs/ARCHITECTURE.md` for the design and `../CLAUDE.md` for working rules.
